# OpportunityHub 🚀

### Your Personal Student Opportunity Tracker

OpportunityHub is a student-focused platform designed to help students discover, organize, and track career-building opportunities in one place.

From internships and jobs to hackathons, scholarships, and competitions, OpportunityHub helps students manage their applications and stay organized throughout their career journey.

## ✨ Features

- **Opportunity Dashboard** — View your opportunities and application statistics in one place.
- **Opportunity Management** — Add, edit, and delete opportunities.
- **Search and Filters** — Find opportunities by title, company, or category.
- **Application Tracking** — Organize opportunities by status, such as Saved, Interested, and Applied.
- **Opportunity Discovery** — Connect opportunity discovery features with supported API integrations.
- **AI Assistant** — Access AI-powered assistance when the relevant API integration is configured.
- **Persistent Storage** — Keep manually added opportunities in browser storage.
- **Responsive Interface** — Use the dashboard across different screen sizes.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/nameerasadaf/OpportunityHub.git
   ```

2. Navigate to the project directory:

   ```bash
   cd OpportunityHub
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### API Configuration

Some features depend on external API integrations.

- Configure the required API keys as environment variables in your local environment or deployment platform.
- Never commit API keys, passwords, or private credentials to GitHub.
- API routes may require a compatible local or deployed server runtime.
